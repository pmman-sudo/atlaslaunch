# Contributing

Open an issue describing the problem and reproduction steps. For changes, use a branch and include the reason, behavior change, and checks performed. Run `npm test`, `npm run typecheck`, `npm run build`, and the relevant Python tests before requesting review.

Keep secrets, model weights, and private test data out of Git. Do not rewrite raw evidence to improve scores. Label fixture responses and AI-authored review notes. Record human review only when a human has actually assessed the answer. See `docs/DEVELOPER_TEST.md` for external testing.

The project has not yet selected an open-source license. Discuss contribution and redistribution terms with the owner before contributing substantial code.
